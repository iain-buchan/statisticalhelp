Example workbook

 

Menu location: Help > Example workbook.

 

The examples in this help use the data of the example workbook, test.xlsx, installed with StatsDirect. Each method's topic names the sheet and the columns of its example, so that you can select them and compare your results with the help's.

 

Help > Example workbook opens an unsaved copy of it, named Example workbook, so that you can follow an example, change the data and run the methods without touching the installed copy. Save asks where to keep your copy, as Save As does.
