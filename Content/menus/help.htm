Help menu

 

The Help menu holds the learning tools and the help itself.

 

  • Learning opens the lesson library with its tutor, practice questions and learning record, and Learning Options opens its preferences: see Learning.
  • Contents and Index opens the help at its contents page, and Method Selection opens the guide to choosing a statistical method.
  • Check for Updates reads the current version from www.statsdirect.com and tells you whether yours is the latest; if a newer version is there, it offers to close StatsDirect and install it. StatsDirect also checks once, in the background, when it starts.
  • Example workbook opens an unsaved copy of the example workbook that the help's examples use, so that you can try the methods on it and keep the installed copy as it is.
  • About StatsDirect shows the version, the copyright notice and the licence.

 

The help opens offline, in a pane docked at the right of the StatsDirect window: from this menu, from the Help button on the toolbar of a workbook, a report or a script, from F1, and from the Help button of an analysis dialog, each opening the topic of the window or dialog in front. The pane has Back, Forward, Contents and Print, and a box that searches every topic. Pop out moves the help into a window of its own and Dock brings it back, keeping the topic, the history and the place you were reading; Close hides it. While an analysis dialog is open the help floats beside it and returns to the dock when the dialog closes. The topics are those of the web help at www.statsdirect.com/help, installed with the program.
