Tools menu

 

The Tools menu holds the calculator, links to other programs, and R.

 

  • Calculator opens StatsDirect's calculator in its pane.
  • Links to other programs follow: Notepad to begin with, and any you add with Setup Tools. Any command that runs from the Windows Run box runs from here, a web address or a mailto link among them; see Setup Tools.
  • R starts R's own window, its graphical console, with the R installed on your computer; if none is installed, StatsDirect offers to install it. For a script written from a result, use Continue in R and the R script window instead.

 

Checking for updates, once on this menu, is on the Help menu as Check for Updates.
