# Help Editor icon

The StatsDirect turquoise tile and navy delta identify the product family.
An open book and gold pencil identify help authoring. `HelpEditor.svg` is the
editable vector; `HelpEditor.ico` includes ten RGBA frames from 16 to 256 pixels.

Regenerate on Windows with `./Build-Icon.ps1` (Node, Playwright and Edge are
development dependencies only). The delta is converted to vector outlines, so
the application and SVG do not require a particular font. No original help
artwork or StatsDirect application icon is changed. Copyright 2026 Iain Buchan;
distributed under the project's MIT licence.
