New report

 

File > New Report starts an empty report, in a tab named Report with its number until the report is saved. Results go into the report you last selected when an analysis runs, or else into another open report, and when none is open a report is made for them. On Mac, methods whose numbers are entered in the form show their results in the analysis tab first: choose Add to report to keep them. A report is saved as an editable HTML file, which web browsers and StatsDirect open. See the Report window topic for editing a report.
