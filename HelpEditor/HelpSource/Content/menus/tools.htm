Calculator and R commands

 

The former Tools menu has been removed.

  • Analysis > Calculator opens the calculator. It has its own section immediately before Options.
  • File > New R session opens a blank R editor. The R button and Continue in R remain available for working with the R code of an analysis.
  • Help > Check for Updates checks for a newer version of StatsDirect.

Notepad, the external R launcher and Setup Tools are no longer menu commands. To open an external program, use your operating system.
