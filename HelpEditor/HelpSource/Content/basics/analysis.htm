Analysis

 

Follow the instructions above the worksheet when choosing data for an analysis. On Windows, click or hover over Data info to review the data already supplied to the analysis. For a further analysis, use the displayed controls to choose the variables and options for that analysis. On Mac, each analysis opens in its own tab: follow the instructions there, ticking the worksheet columns in the order asked, or typing or pasting the data; columns already selected in the worksheet are used when they fit. The analysis tab names the worksheet it reads, and the completed input steps at its foot list the steps already answered.

 

Analyse on the worksheet toolbar lists the commands of the Analysis, Data and Graphics menus. Type part of a method's name, or of the menu it is in, in Search methods, then choose the method to start it as from its menu. While you search, Search Help looks for the same words in the help. On Mac, Search Worksheet Commands… at the top of the Analysis menu, or Shift-Command-A, opens the same list. The results go to the report you last selected, or to a new report when none is open.

Available under the Analysis menu section at all times:

  • EXACT TESTS ON COUNTS
  • CHI-SQUARE TESTS
  • PROPORTIONS
  • RATES
  • SAMPLE SIZE
  • DISTRIBUTIONS
  • RANDOMIZATION
  • CLINICAL EPIDEMIOLOGY

 

Also available under the Analysis menu section when a workbook is active:

  • DESCRIPTIVE STATISTICS
  • PARAMETRIC METHODS
  • NONPARAMETRIC METHODS
  • ANALYSIS OF VARIANCE
  • REGRESSION AND CORRELATION
  • AGREEMENT ANALYSIS
  • SURVIVAL ANALYSIS
  • META-ANALYSIS
  • CROSSTABS
  • FREQUENCIES

On Mac, these methods are on the Analysis menu at all times, and use the worksheet you selected last, or data typed or pasted into the analysis tab.

 

GRAPHICS has a menu of its own, next to Analysis.

 

At the bottom of the Analysis menu, Calculator has its own section immediately before Options. Calculator is available with any document active.
