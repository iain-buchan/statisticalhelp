Worksheet Learn and AI Assist

The Windows worksheet toolbar has two ways to get guidance. Learn opens the lesson library, including worked examples and practice questions that you can use without an AI connection. AI Assist opens a conversation for the current workbook.

Ask a question

Ask how to organise or analyse your data. At the start of a conversation the assistant uses a short guide based on Statistical Method Selection to ask about your goal, study design and measurement scales. It can search and read the entire bundled Help and draw on general statistical and R knowledge for questions beyond StatsDirect. Leave Share workbook data with AI unticked to ask a question without sharing the workbook. When you press Send, ChatGPT receives your question and can use the relevant Help. Leave names, patient identifiers and other confidential information out of your question. In ordinary use, the recent conversation also provides context. Choose New conversation to leave earlier shared content out.

If you want advice based on worksheet values, tick Share workbook data with AI above the question box. When you enable sharing for a workbook for the first time in the session, the confirmation dialog names that workbook and asks you to confirm that you have removed person identifiers. This confirmation covers the named workbook for the current application session. Another open workbook needs its own confirmation. Simply visiting it does not remove the first workbook's confirmation. Turn sharing off to stop further workbook reads.

Open suggested R code

AI Assist answers questions and leaves worksheet cells unchanged. If a reply includes code, expand R code to see it. Choose Open in R to open an editable script. StatsDirect includes a fixed snapshot of the worksheet values read for that reply. Ask a follow-up to get a new analysis using current approved values.

Review the code, then choose Run in the R window. When R finishes, choose Add output to report to save the text output and charts in a StatsDirect report.

Run a suggested analysis

In the original worksheet, select the cells you intend to analyse and choose Review analysis. The preview shows the method, source worksheet, selected cells, expected input and report destination. You can cancel and check the selection before reopening the review. If the workbook was shared for the suggestion, ask again after changing its data or selection.

Run and add to report opens StatsDirect's usual analysis setup so you can check the input and choose any required settings. StatsDirect runs the calculation locally and puts the result in the report named in the review, or creates a report if none is open. Running it does not send its data or results to ChatGPT.

The assistant can propose seven methods:

  • Paired Student t test
  • Unpaired Student t test
  • Wilcoxon signed ranks test
  • Spearman rank correlation
  • General analysis of agreement
  • Univariate descriptive summaries
  • Tests for departure from normality

For another method, use Analyse on the worksheet toolbar.

Using AI Assist under an organisation's policy

When your organisation restricts data sharing (level 2), AI Assist can still answer questions using packaged Help and suggest an analysis for you to review and run locally. Workbook sharing is unavailable. Each request sends the question you type and relevant Help, while your workbook, earlier conversation and local results stay on your computer.

When your organisation restricts AI (level 3), AI Assist cannot connect. Learn, local help, and the analyses on the Analysis menu remain available. See Script AI for sign-in and Windows policy details.
